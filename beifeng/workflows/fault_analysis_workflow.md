# Fault Analysis Workflow

```text
用户故障描述
  -> wind_fault_analysis
  -> wind_knowledge_query
  -> advice
  -> risk_assessment
  -> 输出诊断建议
```

Key outputs:

- Problem summary
- Possible causes
- Inspection items
- Inspection methods
- Recommended interval
- Maintenance actions
- Risk level
- Shutdown evaluation requirement
- Human confirmation requirement
- Evidence summary
- Missing data
