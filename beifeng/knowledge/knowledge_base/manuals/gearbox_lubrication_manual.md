# 齿轮箱润滑管理手册

## 概述

润滑管理是齿轮箱可靠运行的基础。不当润滑是齿轮箱故障的首要原因，占故障总数的40%以上。

## 润滑油规格

| 项目 | 要求 | 检测方法 |
|------|------|---------|
| 粘度（40°C） | ISO VG 220 ±10% | GB/T 265 |
| 粘度指数 | >90 | GB/T 2541 |
| 酸值 | <1.0 mgKOH/g | GB/T 264 |
| 水分 | <200 ppm | GB/T 260 |
| 清洁度 | NAS 8级或更优 | ISO 4406 |
| 泡沫特性 | <150/0 mL | GB/T 12579 |

## 油样检测周期

| 运行时间 | 检测频率 | 检测项目 |
|---------|---------|---------|
| <2年 | 每6个月 | 常规理化+光谱 |
| 2-5年 | 每3个月 | 常规理化+光谱+铁谱 |
| >5年 | 每2个月 | 全面检测 |

## 换油标准

以下任一指标超标应考虑换油：
- 粘度变化超过±15%
- 酸值>2.0 mgKOH/g
- 水分>500 ppm
- 清洁度劣于NAS 10级
- 光谱分析金属含量趋势性升高

## 滤芯管理

- 压差报警值：0.35 MPa
- 更换周期：压差报警时或每年
- 滤芯精度：10μm（推荐）

## 安全注意事项

- ⚠️ 废油按危废品规范处置
- 高温放油需防烫伤
- 加油时注意油品型号一致
