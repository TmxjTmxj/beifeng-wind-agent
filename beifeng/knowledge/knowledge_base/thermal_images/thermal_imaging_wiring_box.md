# 风电机组红外热成像巡检手册

## 概述

红外热成像检测是风电机组预防性维护的重要手段，可在故障发展早期发现电气连接过热、轴承异常温升、绝缘局部放电等问题。

## 巡检范围

| 检测对象 | 常见热点位置 | 正常温差参考 |
|---------|------------|------------|
| 电气接线盒 | 电缆接头、铜排连接 | <10°C |
| 变流器柜 | IGBT模块、母排 | <15°C |
| 发电机 | 轴承、绕组端部 | <20°C |
| 变压器 | 接线端子、分接开关 | <15°C |
| 齿轮箱 | 轴承座、油冷却器 | <10°C |

## 检测方法

1. **准备**：确认设备运行状态、环境温度、风速
2. **热成像扫描**：标准路径扫描，覆盖所有目标
3. **热点记录**：记录热点温度、环境参考温度、位置照片
4. **温差计算**：热点与正常区域温差
5. **等级评定**：根据温差判定紧急程度

## 热点等级评定

| 温差 | 等级 | 处理建议 |
|------|------|---------|
| <10°C | 观察 | 下次巡检复核 |
| 10-20°C | 关注 | 3个月内安排检查 |
| 20-40°C | 严重 | 1个月内安排检修 |
| >40°C | 危险 | 立即停机检查 |

## 典型热点案例

### 电气连接过热
- **现象**：接线盒内铜排连接处热点，温差25°C
- **原因**：连接螺栓松动导致接触电阻增大
- **处置**：紧固连接，验证温度恢复

### 轴承过热
- **现象**：齿轮箱高速轴轴承座热点，温差18°C
- **原因**：润滑不良或轴承早期损伤
- **处置**：补充润滑脂，安排振动分析

## 安全注意事项

- ⚠️ 电气热点检查需停电隔离
- 热成像检测需注意安全距离
- 高温部位需防烫伤
