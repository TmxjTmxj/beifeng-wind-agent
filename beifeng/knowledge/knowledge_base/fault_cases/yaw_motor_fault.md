# 偏航电机故障案例

## 故障描述

某风电场2MW机组，SCADA报偏航电机过流报警。检查发现2号偏航电机绕组绝缘电阻从正常的50MΩ下降至2MΩ，电机外壳温度78°C（正常约45°C）。拆卸后确认电机驱动端轴承进水锈蚀，导致转子扫膛，绕组局部绝缘损伤。

## 检查方法

1. 万用表和兆欧表检测绕组和绝缘
2. 红外热成像检查电机温度
3. 电机驱动器输出信号检测
4. 拆卸后轴承和绕组检查

## 处置措施

1. 更换偏航电机
2. 检查偏航电机安装密封
3. 更换后验证偏航功能正常
4. 7天后复检电机温度

## 预防建议

- 检查偏航电机安装密封
- 关注偏航电机电流和温度趋势

## 安全注意事项

- ⚠️ 偏航系统维修需确认机舱内安全
- 电气维修需执行停电挂牌
