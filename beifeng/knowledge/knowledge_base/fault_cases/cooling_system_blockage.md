# 散热系统堵塞案例

## 故障描述

某风电场2MW机组夏季运行期间，齿轮箱油温和发电机轴承温度同时偏高。检查发现齿轮箱散热器和发电机冷却器翅片严重积灰，冷却空气流量减少约40%。冷却风扇运行正常但散热效率明显下降。

## 检查方法

1. **散热器目视检查**：翅片积灰程度
2. **进出风温差**：评估散热效率
3. **冷却液检查**：液位和品质
4. **冷却风扇检查**：转速和风量

## 处置措施

1. 使用压缩空气清洁散热器翅片
2. 更换变质的冷却液
3. 清洁后油温和轴承温度恢复正常
4. 建议增加夏季散热器清洁频率

## 预防建议

- 每季度清洁散热器
- 环境恶劣时增加清洁频率
- 建立冷却系统维护台账

## 安全注意事项

- ⚠️ 冷却液属化学品，需按规程处置
- 高温冷却系统维修需防烫伤
- 电气设备冷却系统维修需停电隔离
