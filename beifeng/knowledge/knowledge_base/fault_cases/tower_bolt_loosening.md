# 塔筒螺栓松动案例

## 故障描述

某风电场1.5MW机组投运18个月后例行检查中，发现塔筒第二段法兰面有5颗螺栓预紧力低于设计值的80%（要求≥90%），最大偏差螺栓预紧力仅为设计值的65%。法兰面局部间隙达0.8mm（允许值<0.5mm）。塔筒振动趋势略有增大。

## 检查方法

1. **液压扭矩扳手检测**：逐颗检测预紧力
2. **塞尺检测法兰间隙**：沿法兰周向8点测量
3. **磁粉探伤（MT）**：检查松动螺栓有无裂纹
4. **全站仪测量垂直度**：评估塔筒整体变形
5. **振动趋势对比**：关联螺栓松动程度

## 处置措施

1. 按力矩要求复紧所有松动螺栓
2. 对预紧力低于80%的螺栓标记并加密复检
3. 更换有裂纹的螺栓
4. 复紧后30天、90天分别复检
5. 建立螺栓检查台账

## 预防建议

- 新投运机组6个月后首次检查螺栓预紧力
- 此后每年例行检查
- 大风区域缩短检查周期

## 安全注意事项

- ⚠️ 塔筒螺栓检查需登塔，执行防坠落措施
- 液压扭矩工具使用需培训合格
- 发现螺栓裂纹应立即评估结构安全
