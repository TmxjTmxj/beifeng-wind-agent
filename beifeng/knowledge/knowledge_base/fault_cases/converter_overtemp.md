# 变流器过温案例

## 故障描述

某风电场2.5MW双馈机组夏季运行期间，变流器报IGBT过温报警。网侧IGBT模块温度从正常的65°C升高至92°C（限值95°C），同时变流器输出功率受限至额定80%。现场检查发现变流器柜散热滤网严重积灰，冷却风扇转速正常但风量明显不足。

## 检查方法

1. **红外热成像**：扫描IGBT模块和散热器温度分布
2. **SCADA温度趋势**：关联环境温度和功率
3. **散热系统巡检**：滤网、风扇、冷却液
4. **进出风温差**：评估散热效率
5. **电能质量分析**：排除谐波影响

## 处置措施

1. 清洁散热滤网和翅片
2. 检查冷却风扇运行状态
3. 处理后IGBT温度降至70°C，功率限制解除
4. 建议增加夏季散热器清洁频率

## 预防建议

- 每季度清洁散热滤网，夏季增加频率
- 关注环境温度与IGBT温度的关联趋势
- 优化变流器柜通风设计

## 安全注意事项

- ⚠️ 变流器含高压直流和交流，维修必须由持证人员执行
- 维修前必须确认电容放电完成
- 不得在过温状态下继续运行
