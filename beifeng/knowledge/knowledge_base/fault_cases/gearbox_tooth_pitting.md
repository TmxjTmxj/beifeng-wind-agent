# 齿轮箱齿面点蚀深度案例

## 故障描述

某内陆风电场2MW机组，SCADA持续报齿轮箱油温高报警。油样光谱分析显示Fe含量从正常的15ppm升高至85ppm，铁谱分析发现大量片状磨粒（20-50μm）。振动频谱在高速级啮合频率（GMF=968Hz）处出现边频带，间隔为高速轴转频（16.1Hz），表明存在调幅现象。

## 检查方法

1. **振动频谱深度分析**：时域波形+频谱+包络谱+倒频谱
2. **油样综合分析**：光谱+铁谱+粘度+酸值
3. **内窥镜多点检查**：高速级/低速级/行星级
4. **SCADA趋势关联**：油温/振动/功率三参数关联分析

## 处置措施

1. 内窥镜确认高速级小齿轮点蚀面积12%
2. 判定为严重级，安排计划性停机
3. 更换高速级齿轮副
4. 更换全部润滑油，清洗油路
5. 更换后振动频谱恢复正常

## 预防建议

- 建立油样基线数据，关注偏离趋势
- 啮合频率边频带出现时应高度警惕
- 定期进行内窥镜检查

## 安全注意事项

- ⚠️ 齿轮更换属重大维修，需完整施工方案
- 更换后必须进行传动链对中和动平衡检查
- 废油按危废品规范处置
