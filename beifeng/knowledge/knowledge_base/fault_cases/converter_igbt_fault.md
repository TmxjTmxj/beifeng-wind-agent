# 变流器IGBT故障案例

## 故障描述

某风电场2MW机组运行中突然报变流器故障停机。故障录波显示网侧IGBT上桥臂短路，直流母线电压瞬间从1100V升高至1500V后过压保护动作。检查发现IGBT模块上桥臂芯片表面有烧蚀痕迹，驱动板部分元件损坏。

## 检查方法

1. **故障录波分析**：提取故障前后电压电流波形
2. **万用表和示波器检测**：检查IGBT导通和驱动信号
3. **直流母线检查**：确认母线电容和缓冲电路
4. **驱动板检测**：检查驱动信号和保护功能
5. **红外热成像**：检查其他IGBT模块温度

## 处置措施

1. 更换故障IGBT模块
2. 更换损坏的驱动板
3. 检查直流母线电容和缓冲电路
4. 校验保护参数设置
5. 更换后进行并网测试，验证输出正常

## 预防建议

- 定期进行变流器预防性维护
- 关注IGBT温度趋势
- 检查保护参数设置合理性

## 安全注意事项

- ⚠️ IGBT故障涉及高压，必须由专业电气人员处置
- 更换前必须确认断电和电容放电
- 不得远程复位IGBT故障
