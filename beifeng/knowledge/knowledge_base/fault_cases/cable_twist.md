# 电缆扭缆案例

## 故障描述

某风电场2MW机组偏航角度累积超过720°（2圈），SCADA未触发解缆报警。现场检查发现塔筒内悬垂电缆出现明显扭转，最严重处电缆外护套出现折痕。偏航计数器校验发现计数偏差约180°，导致解缆触发延迟。

## 检查方法

1. **SCADA偏航角度分析**：查看累积偏航角度
2. **目视检查电缆**：沿电缆路径检查外观
3. **偏航计数器校验**：比对SCADA角度与实际角度
4. **解缆功能测试**：手动触发解缆验证功能

## 处置措施

1. 立即执行偏航解缆操作
2. 检查电缆有无损伤（外护套和绝缘层）
3. 校准偏航计数器
4. 本案例电缆外护套有折痕但未伤及绝缘，记录跟踪
5. 优化偏航解缆策略参数

## 预防建议

- 每季度检查偏航解缆功能
- 校验偏航计数器精度
- 关注偏航累积角度趋势

## 安全注意事项

- ⚠️ 解缆操作需确认机舱内安全
- 电缆损伤需专业人员评估
- 不得在扭缆严重时远程偏航
