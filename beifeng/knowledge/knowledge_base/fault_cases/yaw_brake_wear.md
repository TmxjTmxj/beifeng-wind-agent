# 偏航制动器磨损案例

## 故障描述

某风电场1.5MW机组，运维人员发现机组在停机状态下机舱缓慢偏转（偏航漂移），SCADA偏航角度在30分钟内变化约5°。检查发现偏航制动器摩擦片磨损严重，剩余厚度仅6mm（新片20mm），制动液压压力正常但制动力不足。

## 检查方法

1. 摩擦片厚度测量
2. 制动液压压力检测
3. 偏航保持精度测试
4. 偏航制动器弹簧张力测试

## 处置措施

1. 更换偏航制动器摩擦片
2. 检查制动器弹簧张力
3. 调整制动压力
4. 更换后验证偏航保持精度

## 预防建议

- 每6个月检查制动器磨损
- 关注偏航角度漂移趋势

## 安全注意事项

- ⚠️ 偏航制动维修需确认机舱固定安全
- 液压系统维修需释放压力
