# 叶片雷击损伤案例

## 故障描述

某风电场2MW机组在雷暴天气后，无人机巡检发现叶片前缘中段出现烧蚀痕迹，表面涂层碳化变黑，面积约15cm×8cm，深度约3mm。接闪器周围出现放射状裂纹，引下线连接处有烧蚀变色。

## 检查方法

1. **无人机高清摄影**：对烧蚀区域进行多角度拍摄，记录损伤范围
2. **接地电阻测试**：测量叶片根部接地电阻，判断引下线是否导通
3. **内窥镜检查**：通过叶根检查孔进入叶片内部，检查引下线和结构梁连接
4. **超声检测（UT）**：对烧蚀区域周围进行超声扫描，评估内部结构损伤

## 处置措施

1. 记录雷击事件时间、SCADA数据和气象记录
2. 评估损伤等级：
   - **轻度**：仅表面涂层烧蚀 → 安排修补
   - **中度**：烧蚀深入结构层但未穿透 → 安排专业修补
   - **重度**：引下线断路或结构层穿透 → 安排叶片更换
3. 本案例判定为中度，安排修补
4. 修补后30天复检

## 预防建议

- 每年雷雨季前检测防雷系统
- 关注接地电阻趋势变化
- 雷暴后48小时内安排巡检

## 安全注意事项

- ⚠️ 雷击后必须等待30分钟以上方可登塔检查
- 防雷系统检测需由具备资质人员执行
- 不得在雷暴天气进行叶片检查
