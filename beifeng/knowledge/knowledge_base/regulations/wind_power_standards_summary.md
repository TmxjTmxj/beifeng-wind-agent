# 风电运维相关国家标准摘要

## 概述

本文件摘录了与风电运维直接相关的国家标准和行业规范核心条款。

## 主要适用标准

| 标准编号 | 标准名称 | 核心内容 |
|---------|---------|---------|
| GB/T 25383 | 风力发电机组 验收规范 | 机组验收流程和标准 |
| GB/T 19963 | 风电场接入电力系统技术规定 | 并网技术要求 |
| GB/T 31517 | 风力发电机组 设计要求 | 机组设计标准 |
| DL/T 796 | 风力发电场安全规程 | 安全操作要求 |
| DL/T 666 | 风力发电场运行规程 | 运行管理要求 |
| NB/T 31026 | 风电场技术监督规范 | 技术监督体系 |
| IEC 61400-1 | 风力发电机组 设计要求 | 国际设计标准 |
| ISO 10816 | 机械振动 评价标准 | 振动评价限值 |

## 关键条款摘录

### DL/T 796 安全规程要点
1. 登塔作业必须使用防坠落装置
2. 雷暴天气禁止登塔
3. 高压操作必须两人执行
4. 受限空间进入需检测气体

### GB/T 19963 并网要求要点
1. 机组必须具备低电压穿越能力
2. 功率因数范围0.95（超前）~0.95（滞后）
3. 电压偏差±10%内应正常运行
4. 频率49.5-50.2Hz内应正常运行

### ISO 10816 振动评价要点
1. 新交付机组振动值应在A区
2. B区可无限期运行
3. C区应安排检修
4. D区应停机
