# 风电场并网运行规范摘要

## 概述

风电机组并网运行需遵守国家电网调度规程和风电场并网标准。本文件摘录了与运维直接相关的并网规范要点。

## 并网基本要求

### 电能质量
| 参数 | 限值 | 标准依据 |
|------|------|---------|
| 电压偏差 | ±10% Un | GB/T 12325 |
| 频率偏差 | 49.5-50.2 Hz | GB/T 15945 |
| 电压闪变 | Plt ≤ 1.0 | GB/T 12326 |
| 谐波电流 | 按 GB/T 14549 | GB/T 14549 |
| 功率因数 | 0.95（超前）~ 0.95（滞后）| GB/T 19963 |

### 低电压穿越
- 机组必须具备低电压穿越能力
- 电压跌落至20%额定电压时，至少持续625ms不脱网
- 电压恢复后，有功功率恢复速度≥0.1Pu/s

## 并网操作规范

1. **并网前检查**：确认保护定值、通信正常、计量正常
2. **并网许可**：向调度申请并网，获许可后方可操作
3. **并网过程**：按操作票逐项执行，记录时间
4. **并网后确认**：确认功率输出、保护信号、通信正常

## 运维相关要求

1. **保护投退**：不得擅自投退保护，需经调度许可
2. **参数修改**：涉及并网参数的修改需经调度审批
3. **停送电操作**：必须填写操作票，严格执行两票三制
4. **故障记录**：每次故障停机需记录故障代码和时间

## 安全注意事项

- ⚠️ 并网操作必须遵守调度指令
- 不得擅自修改保护定值
- 故障后恢复并网需经调度许可
- 不得绕过并网保护逻辑
