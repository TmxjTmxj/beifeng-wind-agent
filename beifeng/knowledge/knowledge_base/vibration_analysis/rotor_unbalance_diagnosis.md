# 转子不平衡诊断手册

## 概述

转子不平衡是风电机组常见振动故障之一，特征为1倍转频振动分量增大。早期发现并校正可避免轴承过载和进一步损伤。

## 诊断方法

1. **频谱分析**：1倍转频分量幅值突出，占总振动能量60%以上
2. **相位分析**：相位稳定，径向两个方向相位差约90°
3. **启停过程分析**：通过临界转速时振动明显增大
4. **负荷变化测试**：振动与负荷无关，主要与转速相关

## 不平衡原因

- 转子质量分布不均（制造偏差）
- 转子材料脱落或移位
- 轴承磨损导致转子偏心
- 冷却风扇叶片断裂
- 积灰或结冰导致质量偏移

## 校正方法

1. **现场动平衡**：使用动平衡仪在现场进行配重校正
2. **影响系数法**：试重法计算所需配重
3. **多面平衡**：严重不平衡时需要双面校正
4. **验证**：校正后振动1倍频分量应降至允许范围

## 判定标准

| 振动1倍频值 | 评价 | 建议措施 |
|-------------|------|---------|
| <2.5 mm/s | 正常 | 继续监测 |
| 2.5-4.5 mm/s | 关注 | 安排动平衡评估 |
| 4.5-7.1 mm/s | 异常 | 安排动平衡校正 |
| >7.1 mm/s | 危险 | 立即停机校正 |

## 安全注意事项

- ⚠️ 动平衡校正需专业人员操作
- 高速旋转部件附近需保持安全距离
- 校正后必须验证振动水平恢复正常
