# 振动频谱分析手册

## 概述

振动频谱分析是风力发电机组机械故障诊断的核心手段。通过将时域振动信号转换为频域，可以识别不同故障类型的特征频率，实现早期故障预警和精确定位。

## 常见故障特征频率

| 故障类型 | 特征频率 | 频谱特征 |
|---------|---------|---------|
| 转子不平衡 | 1×转频 | 1倍频幅值突出，相位稳定 |
| 轴承外圈损伤 | BPFO | 包络谱中特征频率明显 |
| 轴承内圈损伤 | BPFI | 包络谱中特征频率+转频边带 |
| 轴承滚动体损伤 | BSF | 包络谱中特征频率 |
| 齿轮啮合异常 | GMF±转频 | 啮合频率处出现边频带 |
| 对中不良 | 1×, 2×转频 | 2倍频幅值显著 |
| 结构松动 | 0.5×, 1×, 2× | 多倍频分量丰富 |
| 轴弯曲 | 1×, 2×转频 | 1倍频为主 |

## 分析步骤

1. **确认传感器位置和方向**：轴向/径向/垂直
2. **获取基线数据**：正常运行时的频谱作为参考
3. **总值趋势分析**：关注振动总值变化趋势
4. **频谱特征识别**：匹配故障特征频率
5. **包络分析**：提取轴承早期故障特征
6. **时域波形**：辅助确认冲击特征
7. **多参数关联**：振动+温度+油样综合判断

## ISO 10816 振动评价标准

| 区域 | 评价 | 双馈发电机限值 |
|------|------|--------------|
| A | 新交付机组 | <2.5 mm/s |
| B | 可无限期运行 | 2.5-4.5 mm/s |
| C | 可有限期运行 | 4.5-7.1 mm/s |
| D | 危险，需停机 | >7.1 mm/s |

## 安全注意事项

- ⚠️ 振动监测数据是机械故障的关键指标
- 不得屏蔽振动保护功能
- Critical振动报警应立即停机评估
