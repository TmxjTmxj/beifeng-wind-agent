# SCADA功率曲线异常分析规则

## 概述

功率曲线是风电机组运行状态的综合反映。功率曲线偏离设计曲线可能由多种因素导致，系统化的分析方法可快速定位问题方向。

## 分析流程

### 第1步：数据质量验证
- 风速仪是否正常（对比相邻机组）
- 风向标信号是否合理
- 功率测量传感器是否漂移
- 数据采集是否存在丢包

### 第2步：限功率排查
- 是否存在调度限功率指令
- 是否触发了主动降载策略
- 偏航限位是否影响

### 第3步：气动性能排查
- 叶片前缘侵蚀程度
- 叶片表面污染（昆虫/灰尘）
- 偏航误差是否过大
- 变桨角度零位是否偏移

### 第4步：机械/电气排查
- 变流器输出是否受限
- 发电机效率是否下降
- 齿轮箱传动效率
- 电网电压/频率偏移

## 量化分析方法

### 功率偏差计算
```
功率偏差(%) = (实际功率 - 设计功率) / 设计功率 × 100%
```

### 判定标准
| 功率偏差 | 评价 | 建议措施 |
|---------|------|---------|
| <2% | 正常波动 | 继续监测 |
| 2-5% | 轻度偏离 | 安排排查 |
| 5-10% | 中度偏离 | 建立分析工单 |
| >10% | 严重偏离 | 立即分析 |

### 横向对比法
- 选取同排、同型机组
- 同风速区间功率对比
- 消除风资源差异影响

## 安全注意事项

- ⚠️ 并网相关判断需遵守调度和场站规程
- 不要直接建议并网切换或保护投退
- 数据异常需先确认测量链路可靠性
