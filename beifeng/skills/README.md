# Custom Skills

This directory contains project-level Skill specifications for wind turbine operations and maintenance.

These Skill files describe intended workflows and tool usage. They do not register new runtime behavior by themselves.

Reserved Skills:

- `wind_fault_analysis`: standard wind fault analysis workflow.
- `blade_inspection`: UAV blade inspection and defect assessment workflow.
- `gearbox_diagnosis`: gearbox oil temperature, vibration, and lubrication abnormality workflow.
- `scada_analysis`: SCADA alarm, trend, and power curve analysis workflow.
- `report_generation`: Markdown O&M report generation workflow.
