# SCADA Analysis

## 适用场景

适用于 SCADA 报警、功率曲线异常、风速功率偏差、趋势异常、运行状态诊断和数据质量检查。

## 输入

```json
{
  "problem": "功率曲线异常",
  "component": "SCADA",
  "symptom": "功率曲线异常"
}
```

## 工作流程

1. 识别 SCADA 相关关键词：功率曲线、报警、风速、功率、趋势、限功率。
2. 调用 `wind_knowledge_query` 获取 SCADA 规则、建议和风险评估。
3. 汇总可能原因，包括测风误差、限功率、偏航误差、叶片污染、设备降额等。
4. 输出需要补充的数据和人工确认要求。

## 必须调用的工具

- `wind_knowledge_query`

## 输出格式

```markdown
## 异常概述
...

## 可能原因
...

## 建议检查数据
...

## 分析方法
...

## 风险等级
...

## 安全提示
...

## 缺失数据
...
```

## 安全边界

- 不直接建议并网切换、远程复位、远程停机或绕过保护。
- 涉及并网、限功率策略、保护动作时必须提示人工确认。
- SCADA 数据不足或存在质量问题时必须说明不确定性。
