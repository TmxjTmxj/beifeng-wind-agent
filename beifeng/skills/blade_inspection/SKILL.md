# Blade Inspection

## 适用场景

适用于无人机叶片巡检、叶片裂纹、前缘损伤、表面剥蚀、雷击痕迹、缺陷复检周期和停机评估问题。

## 输入

```json
{
  "problem": "无人机巡检发现叶片疑似裂纹",
  "component": "Blade",
  "symptom": "裂纹",
  "media_metadata": {
    "media_type": "image",
    "blade_id": "unknown"
  }
}
```

## 工作流程

1. 读取巡检描述和图片/视频 metadata。
2. 将叶片、桨叶、裂痕、开裂、表面裂纹等术语标准化。
3. 调用 `wind_knowledge_query` 获取叶片缺陷建议。
4. 输出检测项目、检测方式、复检周期、维修条件、停机评估条件和安全提示。

## 必须调用的工具

- `wind_knowledge_query`

## 输出格式

```markdown
## 缺陷概述
...

## 建议检测项目
...

## 推荐检测方式
...

## 建议复检周期
...

## 维修建议
...

## 停机评估条件
...

## 安全提示
...

## 缺失数据
...
```

## 安全边界

- 不基于图片 metadata 宣称已完成视觉识别。
- 不直接建议远程停机或远程复位。
- 涉及高空作业、吊装、叶片维修时必须提示现场人工确认和安全措施。

## 示例

用户：无人机巡检发现叶片疑似裂纹，是否需要停机？多久复检？
