# Gearbox Diagnosis

## 适用场景

适用于齿轮箱油温升高、轴承振动异常、润滑异常、油样异常、异响和传动链健康诊断问题。

## 输入

```json
{
  "problem": "齿轮箱油温升高",
  "component": "Gearbox",
  "symptom": "油温升高"
}
```

## 工作流程

1. 识别齿轮箱相关症状：油温、振动、润滑、油样、轴承、异响。
2. 调用 `wind_knowledge_query` 获取图谱建议、RAG 证据、advice 和 risk_assessment。
3. 按油温、油样、振动、润滑、冷却系统、运行工况整理排查步骤。
4. 输出维护建议和安全边界。

## 必须调用的工具

- `wind_knowledge_query`

## 安全边界

- 不直接建议远程停机或远程复位。
- 涉及高温部件、转动部件、润滑系统拆检时必须提示停机挂牌、现场确认和安全隔离。
- 缺少温度、振动、油样或报警数据时，应说明“不确定，需要补充数据”。
